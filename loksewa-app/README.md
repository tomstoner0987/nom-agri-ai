# Nom LokSewa — Adhikrit Preparation MVP

A PWA-ready web MVP for Nepal Public Service Commission Section Officer (Shakha Adhikrit) preparation.

## MVP
- Syllabus-aware navigation
- MCQ practice with explanations
- Local mistake notebook
- Mini mock mode
- 90-day study roadmap
- Current-affairs source-first architecture
- Installable PWA shell

## Production roadmap
1. Verify every syllabus/version against PSC primary documents.
2. Build a structured question database from licensed/official-source material.
3. Add authentication, cloud progress, spaced repetition, timer, negative marking and analytics.
4. Add source-backed current affairs ingestion and editorial review.
5. Add Nepali/English/Roman Nepali modes.
6. Add paid plans, institutional/coaching dashboards and referral system.

Competitor research shows the category already has mock-test apps, question banks and AI tutors; differentiation should come from source provenance, officer-specific depth, answer-writing feedback and a strong daily study loop.
